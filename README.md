# Aurea

Aurea é um projeto acadêmico desenvolvido para o evento Fatec Portas Abertas.

A proposta do projeto é apresentar uma plataforma web que simula um aplicativo voltado à organização da vida acadêmica, reunindo ferramentas úteis para estudantes em um único ambiente.

Entre as principais funcionalidades estão:

* Calendário acadêmico para organização de atividades;
* Calculadoras de notas e frequência;
* Espaços para anotações;
* Áreas colaborativas para grupos de estudo compartilharem conteúdos e materiais.

O projeto foi desenvolvido utilizando HTML, CSS e JavaScript, simulando a experiência de um site/aplicativo completo com foco em usabilidade e organização estudantil.
